# Шпаргалка: Python — базовые типы данных и операции

## 🔢 `int` — целые числа

Тип `int` используется для целых чисел:

```python
age = 25
year = 2026
temp = -10
```

Проверить тип:

```python
print(type(age))
```

Результат:

```text
<class 'int'>
```

Целые числа могут быть:

```text
положительными
отрицательными
нулём
```

Например:

```python
num_1 = 10
num_2 = -5
num_3 = 0
```

---

# 🔍 `type()`

Функция `type()` позволяет узнать тип объекта:

```python
age = 25

print(type(age))
```

Результат:

```text
<class 'int'>
```

Для дробного числа:

```python
pi = 3.14

print(type(pi))
```

Результат:

```text
<class 'float'>
```

---

# ➕ Арифметические операции

Пусть есть два числа:

```python
num_1 = 10
num_2 = 3
```

Основные операции:

```python
num_1 + num_2
```

Сложение:

```text
13
```

---

```python
num_1 - num_2
```

Вычитание:

```text
7
```

---

```python
num_1 * num_2
```

Умножение:

```text
30
```

---

```python
num_1 / num_2
```

Обычное деление.

Результат будет типа `float`:

```python
res = 10 / 3

print(res)
print(type(res))
```

---

# ➗ Целочисленное деление `//`

```python
10 // 3
```

Результат:

```text
3
```

`//` возвращает результат деления без дробной части в данном примере.

---

# 🧩 Остаток от деления `%`

```python
10 % 3
```

Результат:

```text
1
```

То есть:

```text
10 = 3 * 3 + 1
```

Остаток:

```text
1
```

---

# ⏫ Возведение в степень `**`

Оператор:

```python
**
```

используется для возведения в степень.

Например:

```python
2 ** 3
```

Результат:

```text
8
```

---

# 📌 Основные арифметические операторы

```text
+   сложение

-   вычитание

*   умножение

/   обычное деление

//  целочисленное деление

%   остаток от деления

**  возведение в степень
```

---

# 🧮 Порядок выполнения операций

Python учитывает приоритет математических операций.

Например:

```python
res = 2 + 2 * 2

print(res)
```

Результат:

```text
6
```

Сначала выполняется:

```text
2 * 2
```

затем:

```text
2 + 4
```

---

# 🔵 Скобки

Скобками можно изменить порядок вычислений:

```python
res = (2 + 2) * 2

print(res)
```

Результат:

```text
8
```

Сначала выполняется выражение внутри скобок.

---

# 🖨️ `print()`

Функция `print()` выводит данные:

```python
print(2, 3, 4, "qaz")
```

Можно передавать несколько значений через запятую.

---

# 🔗 Параметр `sep`

`sep` задаёт разделитель между значениями:

```python
print(22, 33, 44, sep="-")
```

Результат:

```text
22-33-44
```

Можно использовать любой текст:

```python
print(22, 33, 44, sep="-=!=-")
```

---

# 🔚 Параметр `end`

По умолчанию после `print()` происходит переход на новую строку.

Это можно изменить:

```python
print(22, 33, end="=====")
print(44, 55)
```

Результат будет примерно таким:

```text
22 33=====44 55
```

---

# ⌨️ `input()`

`input()` используется для получения данных от пользователя:

```python
user_input = input()

print(user_input)
```

Можно добавить приглашение:

```python
user_name = input("Введи своё имя: ")

print(user_name)
```

---

# ⚠️ `input()` возвращает строку

Даже если пользователь вводит число:

```python
user_age = input("Введи свой возраст: ")

print(type(user_age))
```

будет:

```text
<class 'str'>
```

То есть введённое значение пока является строкой.

---

# 🔄 Преобразование в `int`

Чтобы работать с введённым числом как с числом:

```python
user_age = input("Введи свой возраст: ")

user_age = int(user_age)
```

После преобразования:

```python
print(type(user_age))
```

получим:

```text
<class 'int'>
```

Теперь можно выполнять арифметические операции:

```python
res = user_age + 1

print("Поздравляем! Тебе", res, "лет")
```

---

# ✂️ Короткая запись

Можно сразу преобразовать результат `input()`:

```python
user_age = int(input("Введи свой возраст: "))
```

Внутри сначала выполняется:

```python
input(...)
```

затем:

```python
int(...)
```

---

# 🆔 `id()` после преобразования

Можно посмотреть идентификатор объекта:

```python
user_age = input("Введи свой возраст: ")

print(type(user_age))
print(id(user_age))
```

После преобразования:

```python
user_age = int(user_age)

print(type(user_age))
print(id(user_age))
```

Переменная начинает ссылаться уже на объект другого типа.

Было:

```text
str
```

Стало:

```text
int
```

---

# ✏️ Сокращённые операторы присваивания

Есть запись:

```python
num = 10
num = num + 11
```

Её можно записать короче:

```python
num = 10
num += 11
```

Результат одинаковый.

---

# 📌 Сокращённые записи

Например:

```python
num += 3
```

то же самое, что:

```python
num = num + 3
```

---

```python
num *= 3
```

то же самое, что:

```python
num = num * 3
```

---

```python
num //= 3
```

то же самое, что:

```python
num = num // 3
```

Аналогично работают и другие арифметические операторы.

---

# 🔍 Операторы сравнения

Пусть:

```python
num_1 = 10
num_2 = 7
```

Можно сравнить значения:

```python
num_1 == num_2
```

Равны ли значения.

---

```python
num_1 != num_2
```

Не равны ли значения.

---

```python
num_1 > num_2
```

Первое больше второго.

---

```python
num_1 < num_2
```

Первое меньше второго.

---

```python
num_1 >= num_2
```

Первое больше или равно второму.

---

```python
num_1 <= num_2
```

Первое меньше или равно второму.

---

# 📌 Операторы сравнения

```text
==  равно

!=  не равно

>   больше

<   меньше

>=  больше или равно

<=  меньше или равно
```

Результатом сравнения является:

```text
True
```

или:

```text
False
```

---

# ⚠️ `=` и `==`

Это разные операторы.

Присваивание:

```python
age = 25
```

Сравнение:

```python
age == 25
```

То есть:

```text
=   присвоить значение

==  сравнить значения
```

---

# 🔵 `float` — дробные числа

Тип `float` используется для чисел с дробной частью:

```python
pi = 3.14
temp = -14.0
zero = 0.0
```

Проверить тип:

```python
print(type(pi))
```

Результат:

```text
<class 'float'>
```

---

# 🔢 `_` внутри чисел

Для удобства чтения больших чисел можно использовать `_`:

```python
num = 1_000_000
```

Для Python это обычное число.

```python
print(num)
print(type(num))
```

Тип:

```text
int
```

То же самое можно делать с `float`:

```python
num = 1_000_000.345_567
```

Символ `_` нужен только для удобства чтения кода.

---

# ➗ Операции с `float`

С дробными числами доступны те же арифметические операции:

```python
num_1 = 10.1
num_2 = 3.1
```

Например:

```python
num_1 + num_2
num_1 - num_2
num_1 / num_2
num_1 * num_2
num_1 // num_2
num_1 % num_2
num_1 ** num_2
```

---

# ⚠️ Особенность `float`

Иногда результат вычисления с дробными числами выглядит неожиданно:

```python
print(0.1 + 0.2)
```

Результат:

```text
0.30000000000000004
```

Это связано с тем, как дробные числа хранятся в памяти компьютера.

Поэтому `float` не всегда хранит десятичное значение абсолютно точно.

---

# 🎯 `round()`

Функция `round()` используется для округления:

```python
res = 0.1 + 0.2

new_res = round(res, 2)

print(new_res)
```

Результат:

```text
0.3
```

---

# 🔢 Количество знаков в `round()`

Например:

```python
num = 12345.63519
```

Округление до одного знака после точки:

```python
round(num, 1)
```

До двух:

```python
round(num, 2)
```

До трёх:

```python
round(num, 3)
```

---

# ↩️ Округление до десятков и сотен

В `round()` можно передавать отрицательные значения:

```python
round(num, -1)
```

Округление до десятков.

```python
round(num, -2)
```

Округление до сотен.

```python
round(num, -3)
```

Округление до тысяч.

---

# 💰 `Decimal`

Когда нужна более точная работа с десятичными числами, можно использовать `Decimal`.

Сначала импортируем:

```python
from decimal import Decimal
```

Создаём значения:

```python
a = Decimal("0.1")
b = Decimal("0.2")
```

Складываем:

```python
res = a + b

print(res)
```

Результат:

```text
0.3
```

В отличие от:

```python
0.1 + 0.2
```

---

# ⚠️ `Decimal` создаём из строки

На занятии использовали:

```python
Decimal("0.1")
```

и:

```python
Decimal("0.2")
```

То есть число передаётся в виде строки.

---

# 🔄 `Decimal` в `float`

При необходимости можно преобразовать результат:

```python
new = float(res)

print(new)
print(type(new))
```

Теперь тип:

```text
float
```

# ✅ `bool` — логический тип

Тип `bool` имеет только два значения:

```python
True
False
```

Например:

```python
is_sun = True
is_running = False
```

Проверить тип:

```python
print(type(is_sun))
```

Результат:

```text
<class 'bool'>
```

---

# 🔍 Сравнения возвращают `bool`

Например:

```python
num_1 = 10
num_2 = 7

res = num_1 == num_2
```

Результат:

```text
False
```

Тип результата:

```python
print(type(res))
```

```text
<class 'bool'>
```

Другой пример:

```python
res = num_1 >= num_2
```

Результат:

```text
True
```

---

# 🔗 Логический оператор `and`

`and` требует, чтобы оба значения были истинными.

```python
True and True
```

Результат:

```text
True
```

Но:

```python
True and False
```

Результат:

```text
False
```

Упрощённо:

```text
and → И
```

---

# 🔀 Логический оператор `or`

Для `or` достаточно, чтобы хотя бы одно значение было истинным.

```python
True or False
```

Результат:

```text
True
```

Упрощённо:

```text
or → ИЛИ
```

---

# 🔄 Логический оператор `not`

`not` меняет логическое значение на противоположное.

```python
not True
```

Результат:

```text
False
```

А:

```python
not False
```

даст:

```text
True
```

Упрощённо:

```text
not → НЕ
```

---

# 📌 Логические операторы

```text
and  → оба условия должны быть True

or   → достаточно одного True

not  → меняет True на False и наоборот
```
