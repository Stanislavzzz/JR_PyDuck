# 📦 Переменная

Переменная позволяет сохранить значение.

```python
age = 32
```

Здесь:

```text
age → имя переменной
32  → значение
```

Вывести значение:

```python
print(age)
```

---

# 🔎 `type()`

Функция `type()` показывает тип объекта.

```python
age = 32

print(type(age))
```

Результат:

```text
<class 'int'>
```

Если изменить значение:

```python
age = "one"

print(type(age))
```

получим:

```text
<class 'str'>
```

Python использует динамическую типизацию.

Поэтому одна переменная может в разное время ссылаться на объекты разных типов:

```python
age = 32
age = "one"
```

---

# 🧠 Где хранятся переменные

Важно различать:

```text
переменную
```

и:

```text
объект
```

Например:

```python
age = 32
```

Упрощённо:

```text
age → ссылка на объект 32
```

Переменная не является самим объектом.

Она хранит ссылку на объект в памяти.

---

# 🆔 `id()`

Функция `id()` возвращает идентификатор объекта.

```python
age = 32

print(id(age))
```

Если присвоить переменной другой объект:

```python
age = "one"

print(id(age))
```

идентификатор обычно изменится.

Упрощённо:

```text
age → 32
```

затем:

```text
age → "one"
```

Переменная начинает ссылаться на другой объект.

---

# 🔄 Переприсваивание переменной

```python
user = "Bob"

user = "Anna"

print(user)
```

Результат:

```text
Anna
```

Предыдущее значение переменной заменяется новым.

Точнее:

```text
user
```

начинает ссылаться на другой объект.

# 📝 Имена переменных

По PEP 8 обычные переменные принято писать в стиле:

```text
snake_case
```

Например:

```python
user_name = "Bob"
user_age = 32
total_price = 1000
```

---

# ✅ Допустимые имена

Можно использовать:

```python
name
name_1
name2
name_user
```

Имя может содержать:

```text
буквы
цифры
_
```

---

# ⚠️ Имя нельзя начинать с цифры

Нельзя:

```python
1name = "Bob"
```

Можно:

```python
name1 = "Bob"
```

или:

```python
name_1 = "Bob"
```

---

# 🐍 `snake_case`

Для обычных переменных Python рекомендует:

```python
user_name
first_name
total_amount
```

То есть слова разделяются символом:

```text
_
```

---

# ⚠️ `camelCase`

Так написать технически можно:

```python
nameUser = "Bob"
```

Но для обычных переменных в Python это не соответствует рекомендациям PEP 8.

Лучше:

```python
user_name = "Bob"
```

---

# 🔒 Имя с `_`

Можно написать:

```python
_user = "Bob"
```

Начальный `_` имеет специальный смысл по соглашению Python.

Обычно он означает:

```text
это внутреннее имя
его не предполагается использовать напрямую извне
```

Это соглашение, а не настоящая защита.

---

# `_` как имя переменной

Можно использовать:

```python
_ = "Bob"

print(_)
```

Это обычное допустимое имя переменной.

Но часто `_` используют, когда значение не имеет значения.

Например:

```python
for _ in range(5):
    print("Hello")
```

Здесь переменная цикла нам фактически не нужна.

---

# 🔠 Константы

PEP 8 рекомендует записывать имена констант заглавными буквами:

```python
MAX_SIZE = 100
PI = 3.14
DEFAULT_USER = "Bob"
```

Стиль:

```text
UPPER_CASE
```

Например:

```python
USER = "Bob"
```

---

# ⚠️ Константы в Python не защищены

Можно написать:

```python
USER = "Bob"

USER = "Anna"
```

Python это разрешит.

То есть технически:

```text
USER
```

остаётся обычной переменной.

Заглавные буквы — это соглашение:

```text
это значение предполагается не изменять
```

---

# 🧩 Основные стили именования

```text
snake_case
```

Используется для переменных и функций:

```python
user_name
total_price
```

```text
UPPER_CASE
```

Обычно используется для констант:

```python
MAX_SIZE
DEFAULT_PORT
```

```text
CamelCase
```

Обычно используется для классов:

```python
User
UserProfile
DatabaseConnection
```
